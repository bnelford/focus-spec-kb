# FOCUS Timeline

> Chronological overview of major FOCUS milestones from inception through early 2026.

## 2023

| Date | Event |
|---|---|
| **January 2023** | Decision to migrate from FinOps Foundation's Open Billing working group to a standalone Linux Foundation JDF project |
| **2023** | FOCUS Project officially kicks off under Linux Foundation governance |
| **2023** | v0.5 preview release — establishes foundational schema concepts |
| **November 2023** | FOCUS 1.0 preview — expanded specification covering cloud and SaaS datasets, open-source converter and validator tools |

## 2024

| Date | Event |
|---|---|
| **March 2024** | Broadcom Tanzu CloudHealth releases FOCUS FlexReport template |
| **June 20, 2024** | **FOCUS 1.0 General Availability** — 43 columns, native support announced by AWS, Azure, GCP, Oracle |
| **June 2024** | AWS Data Exports for FOCUS 1.0 enters general availability |
| **June 2024** | GCP launches FOCUS BigQuery view and Looker Template |
| **November 7, 2024** | **FOCUS 1.1 ratified** — deeper cloud support, enhanced ETL metadata, normative changes to existing columns |

## 2025

| Date | Event |
|---|---|
| **May 29, 2025** | **FOCUS 1.2 ratified** — SaaS/PaaS support, InvoiceId, virtual currencies, BillingAccountType, SubAccountType |
| **Late 2025** | Azure FOCUS 1.2 billing exports enter Public Preview |
| **December 4, 2025** | **FOCUS 1.3 ratified** — Contract Commitment dataset, allocation columns, data recency/completeness |
| **December 2025** | Linux Foundation press release announces expanded vendor support for FOCUS 1.2 |

## 2026

| Date | Event |
|---|---|
| **Early 2026** | FOCUS 1.4 under active development |
| **April 2026** | Current date — 607+ commits on working_draft, 232 open issues |
| **June 8–11, 2026** | FinOps X 2026 (San Diego) — dedicated FOCUS Lab planned |

## Version Summary

| Version | Date | Key Theme |
|---|---|---|
| v0.5 | 2023 | Preview/foundation |
| v1.0 GA | June 2024 | Cloud billing standard (43 columns) |
| v1.1 | November 2024 | Deeper cloud support, ETL metadata |
| v1.2 | May 2025 | SaaS/PaaS, invoicing, virtual currencies |
| v1.3 | December 2025 | Contracts, allocation, data quality |
| v1.4 | TBD 2026 | Data center, AI billing (expected) |
